OpenJev Dataset Atlas

Candidate training data for OpenJev, in four groups. Each entry has one real row from the dataset (checked 2026-09-17), the same row as an OpenJev request, and the training label. OpenJev uses the Jev API format: one state, named questions of type noul, choice, or score, and one flag token per option. Most option lists in these samples show the format only.
