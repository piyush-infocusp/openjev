# 2025-rlcr

**Citation:** Damani et al., 'Beyond Binary Rewards: Training LMs to Reason About Their Uncertainty' (RLCR), ICLR 2026.
**arXiv:** https://arxiv.org/abs/2507.16806
**Local PDF:** ../papers/2025-rlcr.pdf (highlighted: ../papers/2025-rlcr.highlighted.pdf)

**Model sizes used:** Qwen2.5-7B base (p5) only.

**Recipe compared:** RLVR (binary reward) vs RLCR (correctness + Brier on verbalized confidence) vs post-hoc classifier; RL from base, no KL (p5).

## Key findings

- **Binary-reward RL degrades calibration; Brier reward fixes it.** (p.1)
  > "While ordinary RL hurts calibration, RLCR improves it."
- **Same accuracy, much better calibration.** (p.2)
  > "RLCR matches the task accuracy of RLVR while substantially improving calibration, on in-domain problems, reducing expected calibration error from 0.37 →0.03 on HotpotQA"
- Reward = correctness **plus** Brier; a bounded proper score is provably fine. (p.2)
  > "RRLCR(y, q, y∗) = Rcorrectness(y, y∗) + RBrier(y, q, y∗) = 1y≡y∗−(q −1y≡y∗)2"
- **Log score is non-monotonic with correctness bonus**; prefer bounded Brier. (p.22)
  > "the log score’s calibration term can outweigh the correctness bonus, creating a non-monotonic reward landscape"
- **Calibration-only reward collapses accuracy.** (p.28)
  > "Calibration RL (Full-Sequence) collapses to near-zero accuracy"

## Relevance to OpenJev

OpenJev context: Gemma 4 E2B (2.3B effective), option-scoring flag head, SFT then exact-PG/GRPO with a Brier reward.

Strongest direct support for a Brier reward combined with a correctness term (not Brier alone). Only 7B tested, so no size trend; ECE 0.37->0.03 is on a verbalized-confidence setup, whereas ours is a probability head, so the transfer is conceptual. Note it started from base with no SFT, but 7B base.
